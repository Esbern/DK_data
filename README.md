# DK_data

Example notebooks for downloading, exploring, and visualizing Danish spatial data with Python.

## Notebook series

1. `/home/runner/work/DK_data/DK_data/notebooks/01_load_danish_boundaries.ipynb`  
   Load Danish administrative boundaries from a public GeoJSON source and plot them with GeoPandas.
2. `/home/runner/work/DK_data/DK_data/notebooks/02_access_osm_danish_data.ipynb`  
   Access Danish OpenStreetMap data for Copenhagen and visualize roads/parks.
3. `/home/runner/work/DK_data/DK_data/notebooks/03_interactive_danish_map.ipynb`  
   Create an interactive Folium map using Danish boundary data.

## Suggested environment

Use Python 3.10+ and install geospatial libraries in your notebook environment, for example:

```bash
pip install geopandas matplotlib osmnx folium
```
